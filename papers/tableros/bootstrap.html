Laboratorio de bootstrap

El bootstrap aproxima la distribución muestral de un estimador remuestreando con reemplazo la propia muestra. Elige un estadístico, genera una muestra de una población con salarios sesgados y compara el error estándar y el intervalo al 95% de cinco métodos. Con “Simular cobertura” se repite todo cientos de veces para ver qué tan seguido cada intervalo contiene el valor verdadero.

Población: salario log-normal (mediana 55, media 65 pesos por hora). En la regresión, log(salario) = 2 + 0.08·escolaridad + error, con varianza que crece con la escolaridad.

Normal y percentil

Normal: usa el error estándar bootstrap (desviación estándar de las réplicas) y el intervalo θ̂ ± 1.96·EE. Percentil: toma directamente los cuantiles 2.5 y 97.5 de las réplicas θ̂*; no supone normalidad, pero hereda el sesgo del estimador.

Percentil-t

En cada réplica calcula t* = (θ̂* − θ̂)/EE*. El intervalo es [θ̂ − t*0.975·EE, θ̂ − t*0.025·EE]. Al estandarizar, suele tener mejor cobertura con distribuciones sesgadas y muestras chicas. Para la mediana, EE* se obtiene con un bootstrap anidado de 25 réplicas.

Jackknife y m de n

Jackknife: recalcula el estimador dejando fuera una observación a la vez; es exacto para estadísticos suaves, pero falla con la mediana. Bootstrap m de n: remuestrea m = n/4 observaciones y reescala por √(m/n); sirve cuando el bootstrap usual no es consistente.
